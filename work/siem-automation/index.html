01 / THE CONTEXT

Detection is useful only when it is actionable.

Hands-on security-monitoring lab using self-developed applications; not presented as a production enterprise SOC.

02 / MY ROLE

What I actually worked on.

  • Integrated application events from intentionally vulnerable web applications into Splunk and Wazuh.
  • Created custom detection rules tied to selected endpoints and attack activity.
  • Built n8n automation to evaluate alert severity/priority and send notifications to Discord.
  • Iterated on rules by generating and reviewing controlled test events.
03 / WORKFLOW

How I approached it.

01

Connect

Forward application events into Splunk and Wazuh for analysis.

02

Detect

Write tailored rules for conditions observed at selected endpoints.

03

Route

Use n8n conditions to forward priority and severity-related notifications to Discord.

04 / RESULT

What came out of the work.

Produced working application detection and alert-notification workflows in lab environments.

05 / REFLECTION

Understanding the system.

The work connected offensive testing to defensive visibility without claiming it discovered every vulnerability automatically.

A meaningful alert needs a clear condition and useful context - not just a high-severity label.
