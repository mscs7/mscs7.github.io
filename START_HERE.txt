PUBLISH IN GITHUB - WINDOWS / CHROME
-----------------------------------
1. Go to github.com/mscs7/mscs7.github.io. Code -> Download ZIP (BACKUP).
2. Extract this V3 SAFE UPDATE ZIP to a local folder.
3. In your repository, open the branch that GitHub Pages publishes.
4. Choose Add file -> Upload files.
5. Drag ALL WEBSITE CONTENTS from the extracted folder into the upload
   area (NOT the enclosing V3_Safe_Update folder and NOT the ZIP).
6. Paths such as index.html, v3-visuals.js, styles.css, case-study.js,
   and folders work/ and tools/ must sit beside content.js in repo ROOT.
7. Commit changes. Verify deployment in GitHub Actions.
8. Open https://mscs7.github.io/ and hard-refresh with Ctrl+Shift+R.
9. Try the Tools filter, 13 Read story links, terminal, red section dots,
   Gmail/Outlook/LinkedIn/GitHub, light mode and motion pause.

BEST WAY TO EDIT WORK STORIES
----------------------------
1. After publishing, visit:
   https://mscs7.github.io/tools/work-editor.html
2. Pick a work page on the left.
3. Edit title, summary, skills, scope, contributions, outcomes, and the
   case-study story fields. Do NOT change the permanent ID.
4. Click 'Download updated content.js'. This downloads a NEW FILE locally.
5. In GitHub, replace the root content.js with the downloaded version.
6. Commit and refresh the live website.
The editor does NOT edit GitHub by itself. The old work-content.js remains
as a fallback and must not be deleted.

EDIT LOCATION OR SOCIAL URL
---------------------------
Open site-config.js in GitHub -> pencil/Edit -> change values -> commit.
Example: portfolio.profile.location = 'Dubai, United Arab Emirates';

SEO / GOOGLE SEARCH CONSOLE
---------------------------
The sitemap opens as valid-looking XML in the user's screenshot; the
message 'This XML file does not appear to have any style information'
is NORMAL. Google Search Console's new 'Couldn't fetch' status need not
mean invalid XML. Inspect the status details and retry ONLY if there's a
specific issue or after a reasonable processing delay.

Under Sitemaps, submit: sitemap.xml
The sitemap URL must be: https://mscs7.github.io/sitemap.xml
Under URL Inspection, request indexing for a small number of priority
pages ONCE. Google may take days to weeks and ranking is not guaranteed.
A sitemap does not make Google index all pages immediately.

TO ADD A BRAND-NEW CASE STUDY LATER
----------------------------------
It needs: a new project entry in content.js (or work-content.js),
its own work/<new-id>/index.html file with the same data-project ID,
and an entry in sitemap.xml. New artwork requires a new visual module
in v3-visuals.js. Start by copying a current work folder, then update
its page title, canonical link and description; do not copy any client
secrets. Ask for help if you want to add new custom animated modules.
